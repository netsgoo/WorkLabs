# 问鼎 · Ding

A股与港股多标的实时盯盘与到价声音报警工具。问鼎巅峰，鸣金收兵。

## 功能特性

- **多标的同时监控**：支持 A股（如 `sh600519`、`sz002594`）与港股（如 `hk00700`、`hk09988`）同时盯盘，单请求批量拉取行情。
- **到价视觉与声音报警**：到达设定价格时，列表行高亮呼吸灯闪烁，Web Audio 合成音效循环报警，并发送系统桌面通知。
- **提示音定制与音量调节**：内置 4 款合成音效（经典和弦、急促雷达、柔和铃声、警报警笛）与静音模式，支持 0% 至 100% 滑块调节及实时试听。
- **手动停止与闭环调整**：触发后提供醒目的【停止提醒】按钮；停止后可直接改价并重新启动监控，或移除该项。
- **分时走势图联动**：点击任意标的行即刻展开 ECharts 分时走势图，自适应标注昨收参考线与目标价警报线。
- **本地持久化**：所有监控标的、触发条件、刷新频率、音效选择与音量大小均保存在浏览器 `localStorage`，刷新或重启自动恢复。

## 运行方式

纯前端单文件实现，无需 Node.js 或后端服务支撑。双击在现代主流浏览器（Chrome、Edge、Safari 等）中直接打开 `index.html` 即可使用。

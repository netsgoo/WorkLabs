# 🧪 WorkLabs

个人日常工具与实验项目集合。仓库采用 Monorepo 单仓模式管理，每个子目录为独立运行的项目单元。

## 项目列表

| 项目目录 | 项目名称 | 功能概述 | 运行依赖 |
| :--- | :--- | :--- | :--- |
| [`stock-alarm-dashboard/`](./stock-alarm-dashboard/) | 股价提醒台 | A股与港股多标的实时盯盘、到价声音报警、分时图联动与本地配置持久化 | 纯前端单页面，浏览器直接运行 |

## 目录组织规范

后续新增项目请遵循以下规范：

1. **子目录自治**：每个新项目在根目录下建立独立子文件夹，拥有专属说明文档 `README.md`，保持自包含。
2. **零跨项目耦合**：各个工具互不影响，方便单独复制、测试或迁移。
3. **全局索引更新**：新增项目后在根目录表格中登记项目名称、概述与运行方式。
